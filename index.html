How my agents work

From failed job to resolved incident

The pattern behind my telecom operations agents — built on LangGraph with a supervisor that routes on confidence, not guesswork.

Ingest

Logs, mediation jobs and CDR pipeline events streamed via Filebeat & Logstash into OpenSearch.

Detect

Failures surfaced and classified — "PBF map not found", "metafile not received", rating errors.

Retrieve

Hybrid search + reranking over runbooks and past resolutions in a vector store.

Route

Supervisor agent scores confidence and picks the deterministic or exploratory path.

Remediate

Known fixes run as first-class actions — SQL scripts, job re-triggers, re-rating.

Learn

Every outcome is audited and fed back, so the next occurrence is resolved faster.

Human-in-the-loop by design: low-confidence or novel failures are escalated to an engineer with full context instead of being acted on automatically.
